# Media Manager

Application for managing and playing a media library.

> [!NOTE]
>
> - 🏷️ "Media Manager" is a temporary name.
> - 🚧 Project currently under development, with no "official" release yet.

## Overview

Self-contained desktop application for managing and playing a media library. The entire system, processing, and data storage run locally on the user's machine, without relying on external or cloud services.

## How to Use

### Clone the Repository

```bash
git clone https://github.com/igorchaves22/media-manager.git
cd media-manager
```
